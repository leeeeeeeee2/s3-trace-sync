Broadcast & Cloudflare R2 Destination

Asynchronously stream OpenRouter-style conversation traces to Cloudflare R2 (preferred, zero egress fees) or any S3-compatible bucket without blocking Magpie responses.

1. Storage Provider Cloudflare R2 Preferred
Cloudflare R2 Compatibility & Setup Tips:
  • In Cloudflare Dashboard, go to R2 > Manage R2 API Tokens and create a token with Object Read & Write (or Object Write for write-only archiving).
  • R2 encrypts all objects at rest automatically; AWS x-amz-server-side-encryption headers are automatically omitted for R2 per Cloudflare's S3 API spec.
  • Trace uploads include a Content-MD5 digest for integrity verification and automatic collision-safe naming to respect R2's 1 write/sec/key limit (error 10058).
